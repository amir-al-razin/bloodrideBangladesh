# BloodRide

Find a blood donor near the hospital in Dhaka. The hospital approves the request, and eligible donors close by are alerted.

**Start here: [`PROJECT.md`](PROJECT.md)**, a one-page summary of what we're building, what works, and what's next.

| Folder | What it is |
|---|---|
| [`bloodride/`](bloodride/) | The app: database, API, website. How to run it: [`bloodride/README.md`](bloodride/README.md) |
| [`BloodRide_2026-11-21/`](BloodRide_2026-11-21/) | The backlog and the proposal PDFs, plus older planning notes (`PROJECT.md` replaces them where they disagree) |

Quick start: `cd bloodride && ./run.sh` (Linux/Mac) or `.\run.cmd` (Windows), then open http://localhost:3000.
